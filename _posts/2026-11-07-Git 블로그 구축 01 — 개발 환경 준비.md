## 1. 핵심 개념

**Jekyll이란?**

Markdown, HTML 등의 파일을 정적 웹사이트로 변환하는 Ruby 기반 정적 사이트 생성기(Static Site Generator)다.

**사용하는 이유**
- Markdown 파일을 게시글로 변환할 수 있다.
- 게시글과 웹사이트 디자인을 분리할 수 있다.
- 데이터베이스나 별도 웹 서버 없이 GitHub Pages로 배포할 수 있다.

**전체 동작 구조**

Markdown 작성 → Jekyll 빌드 → HTML 생성 → GitHub Pages 배포

## 2. 개발 환경

| 구성 요소 | 역할 |
|---|---|
| Windows | 개발 운영체제 |
| VS Code | 코드 및 Markdown 편집 |
| Git | 버전 관리 |
| GitHub | 소스 코드 저장소 |
| Ruby | Jekyll 실행 환경 |
| Jekyll | 정적 사이트 생성 |
| GitHub Pages | 웹사이트 호스팅 |

## 3. 실습 내용

### 3-1. 개발 도구 설치 및 확인

설치한 도구와 확인된 버전:

```powershell
ruby -v
# ruby 4.0.9 (2026-10-23) [x64-mingw-ucrt]

jekyll -v
# jekyll 4.4.1

git --version
# git version 2.56.0.windows.4
```

### 3-2. Git 사용자 설정

```powershell
git config --global user.name "GitHub ID"
git config --global user.email "GitHub Email"
git config --global --list
```

Git 커밋에 기록될 작성자 정보를 설정한다.

### 3-3. GitHub 저장소 연결

저장소: `htkim1097.github.io`

로컬 경로:

```text
C:\Workspace\Git\htkim1097.github.io
```

```powershell
cd [로컬 프로젝트 경로]

git clone https://github.com/YOUR-ID/YOUR-ID.github.io.git

cd YOUR-ID.github.io

code .
```

GitHub 저장소를 로컬 PC로 Clone하여 VS Code에서 프로젝트를 관리한다.

## 5. 다음에 기억할 것

- Git은 파일의 변경 이력을 관리한다.
- GitHub는 Git 저장소를 원격으로 보관하고 공유하는 서비스다.
- Ruby는 Jekyll이 실행되는 기반 환경이다.
- Jekyll은 Markdown을 HTML 웹사이트로 변환한다.
- GitHub Pages는 생성된 정적 웹사이트를 호스팅한다.
